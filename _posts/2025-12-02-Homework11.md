# Brownian motion

Brownian motion (or Wiener process) is one of the most fundamental stochastic processes in probability theory.  
Originally observed by the botanist Robert Brown in 1827 as the irregular movement of pollen particles suspended in water, it was later formalized by physicists and mathematicians (Einstein, Wiener, Kolmogorov) as a model of **continuous, random evolution over time**.
Today it plays a central role in physics, finan ce engineering, machine learning and probability theory.

## Standard brownian motion (weiner process)

A standard brownian motion $W_t$ is a real-valued continuous-time stocastic process with:

- $W_0 = 0$
- Independent increments:
  increments over non overlapping intervals are independent.
- Stationary Gaussian increments
  For any $0 \le s < t$:  
  $$W_t - W_s \sim \mathcal N (0,t-s)$$  
  In particular:  
  $$W_t \sim \mathcal N (0,t)$$  
So variance grows linearly in time.

## Arithmetic Brownian motion (ABM)

An arithmetic Brownian motion with drift $\mu$ and volatility $\sigma$ is defined as:  
$$X_t = X_0 + \mu t + \sigma W_t$$  
$X_t$ also satisfies the stochastic differential equation:  
$$dX_t = \mu dt + \sigma dW_t \space \space \space X_0=x_0$$  
For each $t$, the distribution is Gaussian:  
$$X_t \sim \mathcal N (x_0 + \mu t, \sigma^2 t)$$  
Thus:

- $\mu$ controls the trend
- $\sigma$ controls the amount of randomness

## Theoretical Properties

### 1. Markov Property

Future evolution depends only on the current value, not the full past:  
$$P(X_{t+h}​∣history)=P(X_{t+h}​∣Xt​)$$  
This makes Brownian motion useful for modelling memoryless processes

### 2 Independent e stationary increments

For $s < t$:

- BM:  
  $$W_t - W_s \sim \mathcal N (0, t-s)$$
- ABM:  
  $$X_t - X_s \sim \mathcal N(\mu (t-s), \sigma^2 (t-s))$$

### 3 Gaussian Process

Any set $X_{t1}, ... , X_{tn}$ :  
$$Cov(X_s,X_t) = \sigma^2 min(s,t)$$

### 4 Quadratic Variation

A key property that distinguishes Brownian motion from smooth functions:
$$[W]_t = t, \space \space \space [X]_t = \sigma^2t$$

## Real world applications

### Finance - Price Modeling

Early financial models (Bachelier, 1900) used **arithmetic Brownian motion** to describe stock prices:
$$X_t = X_0 + \mu t + \sigma W_t$$

Modern models use geometric Brownian motion, but **the noise term is still Brownian motion**.
ABM is used in:

- interest rate models
- pricing spreads
- modeling mean-reversion plus noise
- stochastic volatility models

### Modeling Normal network traffic

Network traffic (packets per second, connection rates, data volume) fluctuates continuously over time due to:

- random user behavior
- timing variability
- background noise
- protocol delays
Many intrusion detection systems (IDS) model legitimate traffic as a _continuous stochastic process_ with:
- **trend** (expected load)
- **volatility** (noise)
- **random fluctuations**
An **arithmetic Brownian motion** is a first approximation of this:
$$X_t = \mu t + \sigma W_t$$
Where:
- $\mu$ = expected traffic growth
- $\sigma$ = “normal noise”
- $W_t$​ = unpredictable fluctuations
Once the normal model is established, deviations from it signal anomalies.
